# 柑仔店彈珠台

目前版本：**v1.12.0**（各版異動見 [CHANGELOG.md](CHANGELOG.md)）

網頁版的台灣古早味糖果彈珠台，用純 HTML / CSS / JavaScript（Canvas）寫成，不需要套件或建置。

## 執行

直接用瀏覽器開啟 `index.html`，或在此資料夾啟動本機伺服器：

```bash
python -m http.server 8765
```

然後開啟 http://localhost:8765 。

## 玩法

1. **投幣**：點投幣按鈕或機台右上的投幣口，換 20 顆彈珠，會從出珠口掉進下方托盤（`C`）
2. **閃燈＋強化孔**：每局開始時，底部落獎區的燈會一直隨機閃。這時可以往藍色按鈕旁的圓形「強化孔」投珠，倍率分 2、4、6、8、10 倍，每升一段直接扣 2 顆，手上不足 2 顆就不能升（`X`）
   - 倍率越高，定燈後亮的 LED 越少：2 倍亮 5 顆，10 倍只亮 1 顆
3. **定燈**：按前面板的藍色按鈕，燈停下來，決定這一局哪幾排有獎。定燈後不能再投強化孔（`D`）
4. **投珠孔**：定燈後點拉桿下方白邊黑心的「投珠孔」投珠，投幾顆都可以，左上角用數字顯示（`B`）。按住投珠孔會自動連續投，按越久越快（約每秒 4 顆加速到 25 顆）
5. **發射**：在檯面上按住滑鼠（或 `空白鍵`）拉長彈簧，放開發射，按越久彈越遠。在檯面上只是輕點（按不到 `TAP_HOLD_MS` 200 毫秒）不會發射，投珠孔的可點範圍也比圓孔大一圈，投多顆時點偏不會誤射；空白鍵和「按住拉彈簧」按鈕不受影響。力道不夠，鋼珠會滾回發射口，可以再射一次
6. **計分**：鋼珠落在**有亮燈的那一排**才算中，得珠 = 倍率 × 投珠數，從出珠口一顆一顆掉進托盤。沒中就銘謝惠顧，投進去的珠都收走

`M` 靜音、`H` 玩法說明（手機版點上方的「?」）、`L` 切換中文 / English（手機版點上方的「EN / 中」）。語言選擇會記在瀏覽器。

**托盤滿了**：托盤最多裝約 190 顆，再多的彈珠會從托盤滿出來、掉到機台外面，但一樣算在持珠數裡。

**紀錄**：「最高分」（單局最高得珠）和「最多持珠」都存在瀏覽器 localStorage，重新整理或關掉再開都會保留。

## 彈珠台大冒險

按「冒險」（或 `Q`）切換到大冒險模式，隨時可以切回經典模式，兩個模式的彈珠分開保留。

- 兩種玩法，在卡片上方切換：
  - **冒險模式**（預設，左邊）：從城堡出發走 14 關的地圖（`adv.map`，每趟冒險重新產生，`genMap`）：草原、山洞、墓園、沙漠、地城、火山、魔王城各 2 層（`SCENES`），第 1 層 2 個節點都是史萊姆（選的是之後的路線）、第 14 層固定魔王巫妖，其他層 2～3 個節點（任何連續 3 層裡一定有 1 層是 3 個節點），每個節點往上連 1～2 條路、不交叉。按「開始冒險」先放過關的音效、按鈕閃 1 秒（`START_FLASH_MS`）再進地圖，停在城堡（`adv.mapStart`）選第 1 層，點了節點才發珠開打，「返回」可回去重選天賦。地圖每個場景畫那個場景的像素背景（`SCENES[].bg`，城堡 `castle`、魔王城 `demon` 是地圖專用的背景，`buildAdvBg(kind, 1)` 固定倍率）；節點圖示只分種類（`NODE_ICONS`：魔物、菁英、魔王、城堡、事件、商人（錢袋），加上寶箱），看不出是哪一隻怪物。節點：遭遇魔物（從該場景的怪物抽）、菁英（第 4 層起；HP ×`ELITE_HP` 1.33、防禦 +1，跟一般怪物一樣半血才狂暴，過關獎勵選 2 次（`ELITE_REWARDS`，`adv.rewardsLeft`；第二次重新抽 3 張，免費重骰、重骰費用也重新算））、寶箱、隨機事件、商人；比例 `NODE_W`（魔物 50、寶箱 20、菁英 15、事件 15、商人 10），每層至少 1 個戰鬥、3 個節點的層不能全是遭遇魔物、菁英不接菁英、寶箱不接寶箱、事件不接事件、商人不接商人、第 13 層（打魔王前一層）一定有 1 個商人（位置隨機，其他節點照常抽、不會再有第二個商人，至少 1 個戰鬥）。商人（`MERCHANT`、`enterMerchant`，跟事件共用 `adv.event`，id `'merchant'`、phase `'shop'`）：擺 3 格道具（`rollShop`，每格照 `SHOP_TIER_W` 一般 50%／稀有 30%／史詩 15%／傳說 5% 抽稀有度，再從該稀有度抽，同一攤盡量不重複），價錢 `SHOP_PRICE` 5／10／20／50 顆；買走的格子變「已售出」（`buyShop`）；重骰 3 格全部重抽（`rerollShop`，費用從「第幾層」顆開始，每次 +50% 無條件進位）；付完至少要留 1 顆（`canPay`）；按「離開」回地圖（`leaveShop`）。隨機事件（`EVENTS`，同一趟盡量不重複，`adv.eventsSeen`）：進入時顯示圖片、描述和選項，選完馬上結算並存檔（`adv.event`），顯示結果後按「繼續」回地圖。勇者祭壇（付 10% 珠，無條件進位 → 過關獎勵 3 選 1）、神秘賭徒（猜正反面，對了 +25% 珠再加過關獎勵 3 選 1、錯了 −25%，無條件捨去，`GAMBLE_PCT`）、受傷的冒險者（付 10% 珠 → 隨機 1 個道具，一般 70%／稀有 30%）、詛咒祭壇（過關獎勵 3 選 1，但下一個戰鬥關卡防禦 +2，`adv.curse`）、迷路（沒有選項，失去 5% 珠，無條件捨去）；付費選項付完至少要留 1 顆，不夠就不能選。事件、寶箱之後往下一站走也照樣補珠、升級。事件中拿到的珠（從魔物走進事件的補珠、賭贏的珠、獎勵的彈珠）先記在 `adv.held`，不從出珠口掉，下一個關卡開始時才一起掉出來。每過一關在過關卡片的地圖上點下一站（`goNode`）。怪物 HP、防禦照層數（用 `MONSTERS[層]` 的數值），怪物只決定外觀和技能（`adv.mon`）。一開始 50 顆彈珠，剩下的彈珠帶到下一關，每過一層往下一站走時補珠（`CAMPAIGN_BONUS` 15 顆起，每升一級 +`LEVEL_BONUS` 2 顆；打倒魔物、打開寶箱、走完事件、逛完商人都算；等級＝過了幾層 `advKills`，跟怪物強度一樣照層數，走寶箱、事件不會比一路打怪弱），失敗就從第 1 關重來；首頁只顯示標題、天賦和「闖關紀錄」按鈕，紀錄要點按鈕查看
  - 冒險進度存檔：每回合開始、選完過關獎勵、關掉或切走頁面時存進 localStorage（`candy-pinball-run`，v2：地圖與走過的路線、目前節點、怪物、菁英、打倒數、關卡、HP、防禦下降、燃燒、雷射筆、持珠、背包、過關獎勵、天賦、重骰費用、待選獎勵、釘子；舊的 v1 存檔讀取時重新產生地圖，接在原本那一關）。下次打開時開場卡片顯示「繼續冒險」和「重新開始」；回合打到一半關掉時，還沒發射的投珠、強化珠退回，已經在檯面上的珠算用掉。落敗、全部通關或沒珠可帶到下一關時刪除存檔；按「重新開始」不會馬上刪，開始新的冒險時才覆蓋。自由挑戰不存
  - 闖關紀錄（`candy-pinball-run-records`）：冒險模式每趟結束（全破、落敗、沒珠可帶到下一關）時依天賦記錄：挑戰次數、全破次數、最遠、最少回合通關、通關最多剩珠、單回合最大傷害／補珠、單顆彈珠最大傷害／補珠，以及最近 10 次的回合數（發射第一顆珠才算一回合）、最後持有彈珠、總共花費彈珠（投進投珠孔、強化孔的珠，退回的不算）、單回合最大傷害（含燃燒、外傷）、單回合最大補珠、單顆彈珠最大傷害（攻擊燈；外傷滾珠落進補珠燈的外傷也算，燃燒、石頭不算）、單顆彈珠最大補珠；選天賦畫面的「闖關紀錄」按鈕打開
  - **自由挑戰**（右邊）：開始前自己選要挑戰哪一隻怪物（星星越多越難，打倒過的會打勾，存在瀏覽器）
- 上方的倍率欄換成像素螢幕，每場出現一隻像素怪物（共 14 隻：史萊姆、蘑菇怪、蝙蝠、蜘蛛、幽靈、南瓜頭、僵屍、木乃伊、骷髏、吸血鬼、小惡龍、地獄犬、石像怪、巫妖），怪物下方顯示 HP
- 每場 50 顆彈珠、不能投幣；每回合最多投 3 顆珠（`BET_CAP`，過關獎勵「投珠」可以提高），**投幾顆就有幾顆鋼珠疊在彈簧上，拉一次彈簧整疊一起射出**（鋼珠會互撞），每顆各自結算；打怪時倍率固定 ×1、亮 7 燈（`ADV_LIT`）；強化孔最多投 3 顆（`MULT_RULES.adv`），每顆讓發射道最下面的金色「強化魔法陣」耐久 +1（`syncBoostCircle`），經過的珠變成強化珠（`b.magic` 含 `'boost'`），落進紅燈時傷害扣完防禦後 ×`BOOST_BALL` 1.5、落進補珠燈時補珠數 ×1.5；這回合最後一顆經過的珠（`lastThrough`：已全部發射、發射道上沒有別顆還沒經過的珠）吸走剩下的所有耐久，`b.magic` 裡放幾個 `'boost'` 就是幾層，倍率 1 + 0.5 × 層數（`boostPw`；模擬只讓強化魔法陣集中時全破率幾乎不變，連天賦魔法陣也集中時燒紅、外傷升到 93～100%，多吸的層數打到 1/4 效果還是太強，所以天賦魔法陣不集中）；強化魔法陣不佔 `eatCap()` 的名額，可以和天賦魔法陣疊在同一顆珠上（珠染天賦色、外面加金環 `drawBoostRing`）；投進強化孔的珠不退回；火焰燈（最終傷害 ×1.5，第二階 ×2，`BOOST_MULT`）只能靠雷射筆（紅）、高功率雷射筆（紫）做出來（經典模式維持 2/4/6/8/10 倍）；投強化孔後至少要留 1 顆投珠（持珠少於 2 顆不能再投強化孔）；中獎不出珠，每顆命中對怪物造成「攻擊 − 防禦」點傷害；打不破防禦就是 0 傷害、怪物會竊笑

  - 骷髏「骨盾」：骨盾有 `BONE_HP` 10 點耐久，彈珠的傷害先扣骨盾，扣完剩下的才打到骷髏（燃燒、外傷、石頭不擋）；每 `BONE_REFILL` 2 回合（回合結束時）恢復滿耐久（`adv.bone`、`adv.boneT`），螢幕上技能名旁顯示剩餘耐久，沙漏預告也照骨盾計算

### 過關獎勵與暴擊（冒險模式）

- 每打倒一隻怪物（最後一隻除外）從獎勵池（`BOONS`）隨機抽 3 樣選 1 樣，效果持續整個冒險、可以疊加；每次先送 `FREE_REROLLS` 1 次免費重骰（裝備好運骰子吊飾再 +1，剩幾次會存檔，`freeRerolls`），用完才花彈珠重骰，第 1 次的費用＝剛打完的關卡數（`adv.monsterIdx + 1`），之後每次 ×1.5 無條件進位（例：第 13 關 13 → 20 → 30 → 45；每次過關重新計算）。每張卡片顯示「目前 → 拿了之後」的數值（`BOON_STAT`），旁邊的「查看數值」按鈕打開完整的數值面板
- 獎勵池：每回合投珠上限 +2、彈珠 +10、每顆投珠增加攻擊力 1（扣防禦前）、每段倍率 +1、紅燈多亮 1 顆（只能拿一次）、攻擊打破防禦時追加 1 點忽視防禦的傷害、加重（獨特的，彈珠重量 ×2，撞釘子反彈與抖動除以重量，也就是減半）、拔掉 5 根釘子（之後每關也少長 5 根，特殊釘子不受影響）、補珠燈每顆多補 1 顆（最多拿兩次，`REFILL_BOON_MAX`）、補珠燈多 1 顆（只能拿一次）、寶箱藍燈 +1／白燈 −1、暴擊率 +20%、暴擊傷害 +50%
- 暴擊：只有命中紅燈會暴擊，基礎機率 5%、傷害 150%（`CRIT_BASE_RATE`、`CRIT_BASE_MULT`）
- 傷害計算（每顆珠各自算）：攻擊 =（倍率 + 基礎倍率）× 基本傷害 + 每珠增傷 + 等級攻擊 → 扣防禦 → 暴擊 → 有打破防禦才加穿透傷害
- 加重彈珠只在大冒險生效，經典模式維持原樣；新的冒險開始時全部清空
- 大冒險的上方列（手機版）不顯示訊息框，改成「寶藏」按鈕（鍵盤 `T`）：上面分道具、裝備兩頁，依稀有度、名稱列出全部，取得過的可以點開看說明和效果；還沒取得過的只顯示黑色輪廓、不能點。取得紀錄存在瀏覽器
