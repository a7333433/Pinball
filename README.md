# 柑仔店彈珠台

目前版本：**v1.1.0**（各版異動見 [CHANGELOG.md](CHANGELOG.md)）

網頁版的台灣古早味糖果彈珠台，用純 HTML / CSS / JavaScript（Canvas）寫成，不需要套件或建置。

## 執行

直接用瀏覽器開啟 `index.html`，或在此資料夾啟動本機伺服器：

```bash
python -m http.server 8765
```

然後開啟 http://localhost:8765 。

## 玩法

1. **投幣**：點投幣按鈕或機台右上的投幣口，換 20 顆彈珠，會從出珠口掉進下方托盤（`C`）
2. **閃燈＋倍率孔**：每局開始時，底部落獎區的燈會一直隨機閃。這時可以往藍色按鈕旁的圓形「倍率孔」投珠，倍率分 2、4、6、8、10 倍，每升一段直接扣 2 顆，手上不足 2 顆就不能升（`X`）
   - 倍率越高，定燈後亮的 LED 越少：2 倍亮 5 顆，10 倍只亮 1 顆
3. **定燈**：按前面板的藍色按鈕，燈停下來，決定這一局哪幾排有獎。定燈後不能再投倍率孔（`D`）
4. **投珠孔**：定燈後點拉桿下方白邊黑心的「投珠孔」投珠，投幾顆都可以，左上角用數字顯示（`B`）。按住投珠孔會自動連續投，按越久越快（約每秒 4 顆加速到 25 顆）
5. **發射**：在檯面上按住滑鼠（或 `空白鍵`）拉長彈簧，放開發射，按越久彈越遠。力道不夠，鋼珠會滾回發射口，可以再射一次
6. **計分**：鋼珠落在**有亮燈的那一排**才算中，得珠 = 倍率 × 投珠數，從出珠口一顆一顆掉進托盤。沒中就銘謝惠顧，投進去的珠都收走

`M` 靜音、`H` 玩法說明（手機版點上方的「?」）、`L` 切換中文 / English（手機版點上方的「EN / 中」）。語言選擇會記在瀏覽器。

**托盤滿了**：托盤最多裝約 190 顆，再多的彈珠會從托盤滿出來、掉到機台外面，但一樣算在持珠數裡。

**紀錄**：「最高分」（單局最高得珠）和「最多持珠」都存在瀏覽器 localStorage，重新整理或關掉再開都會保留。

## 彈珠台大冒險

按「冒險」（或 `Q`）切換到大冒險模式，隨時可以切回經典模式，兩個模式的彈珠分開保留。

- 兩種玩法，在卡片上方切換：
  - **自由挑戰**：開始前自己選要挑戰哪一隻怪物（星星越多越難，打倒過的會打勾，存在瀏覽器）
  - **連續闖關**：從第 1 關史萊姆一路打到第 7 關石像怪。一開始 30 顆彈珠，打倒怪物後剩下的彈珠帶到下一關，每過一關再補 20 顆（`CAMPAIGN_BONUS`），失敗就從第 1 關重來；紀錄最多打倒幾隻、全部通關幾次
- 上方的倍率欄換成像素螢幕，每場出現一隻像素怪物（史萊姆、蝙蝠、幽靈、僵屍、骷髏、小惡龍、石像怪），怪物下方顯示 HP
- 每場 30 顆彈珠、不能投幣；加倍後至少要留 1 顆投珠（持珠少於 3 顆不能再投倍率孔）；中獎不出珠，改成對怪物造成「倍率 × 投珠數 − 防禦」點傷害；打不破防禦就是 0 傷害、怪物會竊笑。防禦越高的怪物 HP 越少
- 定燈後在沒亮燈的排裡隨機多亮一顆綠色「補珠燈」，落進去不造成傷害，改成補回「投珠數 × 2」顆彈珠（`REFILL_MULT`）
- 怪物 HP 歸 0 勝利；彈珠用完還沒打倒就落敗。勝敗場數存在瀏覽器
- 怪物由弱到強：史萊姆 HP 25 / 防禦 0 → 石像怪 HP 19 / 防禦 44。依「30 顆彈珠、最佳打法」估算的勝率約從 95% 降到 53%；後面幾隻只用 ×2 很難打倒，要善用倍率孔
- 每場彈珠數 `ADV_BALLS`、怪物資料 `MONSTERS`（HP、防禦、場景、配色、12×12 像素圖與竊笑表情）都在 `game.js` 開頭

## 檔案

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 頁面結構與側邊面板 |
| `style.css` | 樣式與手機版排版 |
| `game.js` | 規則、物理（釘陣、發射彎軌、落點隔板、托盤）、繪圖、音效與操作 |

規則數值在 `game.js` 最上方：`MULTS`（倍率段數）、`MULT_COST`（升一段扣幾顆）、`litFor`（各倍率亮幾顆燈）、`COIN_BALLS`、`SLOT_COUNT`。
