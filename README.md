# 柑仔店彈珠台

目前版本：**v1.4.0**（各版異動見 [CHANGELOG.md](CHANGELOG.md)）

網頁版的台灣古早味糖果彈珠台，用純 HTML / CSS / JavaScript（Canvas）寫成，不需要套件或建置。

## 執行

直接用瀏覽器開啟 `index.html`，或在此資料夾啟動本機伺服器：

```bash
python -m http.server 8765
```

然後開啟 http://localhost:8765 。

## 玩法

1. **投幣**：點投幣按鈕或機台右上的投幣口，換 20 顆彈珠，會從出珠口掉進下方托盤（`C`）
2. **閃燈＋倍率孔**：每局開始時，底部落獎區的燈會一直隨機閃。這時可以往藍色按鈕旁的圓形「倍率孔」投珠，倍率分 2、4、6、8、10 倍，每升一段直接扣 2 顆，手上不足 2 顆就不能升（`X`）
   - 倍率越高，定燈後亮的 LED 越少：2 倍亮 5 顆，10 倍只亮 1 顆
3. **定燈**：按前面板的藍色按鈕，燈停下來，決定這一局哪幾排有獎。定燈後不能再投倍率孔（`D`）
4. **投珠孔**：定燈後點拉桿下方白邊黑心的「投珠孔」投珠，投幾顆都可以，左上角用數字顯示（`B`）。按住投珠孔會自動連續投，按越久越快（約每秒 4 顆加速到 25 顆）
5. **發射**：在檯面上按住滑鼠（或 `空白鍵`）拉長彈簧，放開發射，按越久彈越遠。力道不夠，鋼珠會滾回發射口，可以再射一次
6. **計分**：鋼珠落在**有亮燈的那一排**才算中，得珠 = 倍率 × 投珠數，從出珠口一顆一顆掉進托盤。沒中就銘謝惠顧，投進去的珠都收走

`M` 靜音、`H` 玩法說明（手機版點上方的「?」）、`L` 切換中文 / English（手機版點上方的「EN / 中」）。語言選擇會記在瀏覽器。

**托盤滿了**：托盤最多裝約 190 顆，再多的彈珠會從托盤滿出來、掉到機台外面，但一樣算在持珠數裡。

**紀錄**：「最高分」（單局最高得珠）和「最多持珠」都存在瀏覽器 localStorage，重新整理或關掉再開都會保留。

## 彈珠台大冒險

按「冒險」（或 `Q`）切換到大冒險模式，隨時可以切回經典模式，兩個模式的彈珠分開保留。

- 兩種玩法，在卡片上方切換：
  - **冒險模式**（預設，左邊）：從第 1 關史萊姆一路打到第 14 關巫妖（共 14 隻怪物，越後面越強）。一開始 50 顆彈珠，打倒怪物後剩下的彈珠帶到下一關，每過一關再補珠（`CAMPAIGN_BONUS` 15 顆起，每升一級 +`LEVEL_BONUS` 2 顆），失敗就從第 1 關重來；首頁只顯示最佳紀錄（最多打倒幾隻、全部通關幾次）
  - **自由挑戰**（右邊）：開始前自己選要挑戰哪一隻怪物（星星越多越難，打倒過的會打勾，存在瀏覽器）
- 上方的倍率欄換成像素螢幕，每場出現一隻像素怪物（共 14 隻：史萊姆、蘑菇怪、蝙蝠、蜘蛛、幽靈、南瓜頭、僵屍、木乃伊、骷髏、吸血鬼、小惡龍、地獄犬、石像怪、巫妖），怪物下方顯示 HP
- 每場 50 顆彈珠、不能投幣；每回合最多投 3 顆珠（`BET_CAP`，過關獎勵「投珠上限」可以提高），**投幾顆就有幾顆鋼珠疊在彈簧上，拉一次彈簧整疊一起射出**（鋼珠會互撞），每顆各自結算；倍率從 ×1 起跳亮 7 燈，倍率孔每投 1 顆加 1 倍、少一顆燈（最高 ×7 亮 1 燈，經典模式維持 2/4/6/8/10 倍）；加倍後至少要留 1 顆投珠（持珠少於 2 顆不能再投倍率孔）；中獎不出珠，每顆命中對怪物造成「倍率 − 防禦」點傷害；打不破防禦就是 0 傷害、怪物會竊笑
- 定燈後在沒亮燈的排裡隨機多亮一顆綠色「補珠燈」，落進去不造成傷害，改成每顆補 2 顆彈珠（`REFILL_MULT`），這回合第一顆中還會退回投進倍率孔的珠
- 疊珠加成：同一回合第 k 顆落進同一顆燈的珠加成 k − 1；攻擊燈是攻擊 +(k − 1)（扣防禦前，會吃暴擊），補珠燈是多補 k − 1 顆。沙漏預告也會算進去
- 怪物 HP 歸 0 勝利；彈珠用完還沒打倒就落敗。勝敗場數存在瀏覽器
- 等級：從 Lv1 開始，每打倒一隻怪物升 1 級；每升一級過關補珠 +2，每 2 級每顆珠攻擊 +1（扣防禦前）。自由挑戰當作前面的怪物都打過
- 怪物由弱到強：史萊姆 HP 25／防禦 0 → 巫妖 HP 496／防禦 7（HP = 舊版 ×（1 + 0.15 × 第幾關））。依模擬（多顆發射、等級成長、有過關獎勵、不計道具、每回合選最划算的打法）懂得選獎勵全破約 40%、隨便選約 8%，每隻約 20～30 回合，真人玩應該會再難一些
- 每場彈珠數 `ADV_BALLS`、怪物資料 `MONSTERS`（HP、防禦、場景、配色、12×12 像素圖與竊笑表情）都在 `game.js` 開頭

### 寶箱與道具（冒險模式）

- 每兩隻怪物之間有一個寶箱關卡（HP 1、不補 30 顆，補珠在打完怪物後進寶箱時給）。落獎區 11 排全亮白燈；定燈前每投 1 顆倍率珠（最多 3 顆）寶箱升一級，燈色累加：1 顆 3 排藍燈、2 顆再加 2 排紫燈、3 顆再加 1 排橘燈（`CHEST_LANES`）。定燈後只能投 1 顆珠，落在哪一排就從該等級的道具池抽一個：白燈一般、藍燈稀有、紫燈史詩、橘燈傳說
- 大冒險的托盤往左縮，托盤和投珠孔之間由上到下是狀態按鈕（鍵盤 `S`）和背包按鈕（右上角顯示道具數，鍵盤 `I`）。狀態按鈕開啟數值面板，列出投珠上限、每關補珠、每顆珠的攻擊與暴擊、其他過關獎勵效果、已擁有道具和過關獎勵；背包視窗可以看說明和使用道具
- 道具只能在冒險模式的怪物關卡使用，各有使用時機（定燈前／定燈後發射前／兩者皆可）；闖關失敗從第 1 關重來時背包清空
- 道具清單（`ITEMS`）：
  - 一般：銀幣（+10 顆）、雷射筆（紅）（這回合攻擊燈 +1，定燈前）、假彈珠（倍率或投珠隨機 +1，定燈後只加投珠）、雷射筆（綠）（這回合補珠燈 +1，定燈前）、石頭（1 點無視防禦傷害）
  - 稀有：鹽酸（怪物防禦 −1）、沉重彈珠（這回合每顆珠基本傷害 +1）
  - 史詩：沙漏（這回合鋼珠全部落下後先預告每顆的結果，可選擇保留或返回這回合開始前，退回這回合投的珠、用掉的道具不退）、鋁箔包飲料（定燈後把亮著的紅燈全變成補珠燈）
  - 傳說：柑仔店老闆的鑰匙（拿回這一關投出去、沒被補回的彈珠）、搖晃機台（定燈後點檯面任何地方放下 1 顆彈珠，從那裡落下，其他的珠照常發射）
- 彈珠用完時背包裡還有銀幣、假彈珠或可用的鑰匙，就不會直接判輸

### 過關獎勵與暴擊（冒險模式）

- 每打倒一隻怪物（最後一隻除外）從獎勵池（`BOONS`）隨機抽 3 樣選 1 樣，效果持續整個冒險、可以疊加；可以花彈珠重骰，第 1 次 1 顆、之後每次多 1 顆（每張獎勵卡重新計算）
- 獎勵池：每回合投珠上限 +2、彈珠 +10、每顆投珠增加攻擊力 1（扣防禦前）、每段倍率 +1、紅燈多亮 1 顆、攻擊打破防禦時追加 1 點忽視防禦的傷害、彈珠重量 +0.5（撞釘子反彈與抖動除以重量）、隨機拔掉 5 根釘子、補珠燈每顆多補 2 顆、補珠燈多 1 顆、寶箱藍燈 +1／白燈 −1、暴擊率 +20%、暴擊傷害 +50%
- 暴擊：只有命中紅燈會暴擊，基礎機率 5%、傷害 150%（`CRIT_BASE_RATE`、`CRIT_BASE_MULT`）
- 傷害計算（每顆珠各自算）：攻擊 =（倍率 + 基礎倍率）× 基本傷害 + 每珠增傷 + 等級攻擊 → 扣防禦 → 暴擊 → 有打破防禦才加穿透傷害
- 拔釘子、加重彈珠只在大冒險生效，經典模式維持原樣；新的冒險開始時全部清空
- 大冒險的上方列（手機版）不顯示訊息框，改成「寶藏」按鈕（鍵盤 `T`）：依稀有度、名稱列出所有道具，取得過的可以點開看說明和效果；還沒取得過的只顯示黑色輪廓、不能點。取得紀錄存在瀏覽器

## 檔案

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 頁面結構與側邊面板 |
| `style.css` | 樣式與手機版排版 |
| `game.js` | 規則、物理（釘陣、發射彎軌、落點隔板、托盤）、繪圖、音效與操作 |

規則數值在 `game.js` 最上方：`MULT_RULES`（經典與大冒險各自的倍率段數、升一段扣幾顆）、`litFor`（各倍率亮幾顆燈）、`COIN_BALLS`、`SLOT_COUNT`。
