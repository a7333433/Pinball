# 柑仔店彈珠台

網頁版的台灣古早味糖果彈珠台，用純 HTML / CSS / JavaScript（Canvas）寫成，不需要套件或建置。

## 執行

直接用瀏覽器開啟 `index.html`，或在此資料夾啟動本機伺服器：

```bash
python -m http.server 8765
```

然後開啟 http://localhost:8765 。

## 玩法

1. **投幣**：換 20 顆彈珠，會從出珠口掉進下方托盤（`C`）
2. **閃燈＋倍率孔**：每局開始時，底部落獎區的燈會一直隨機閃。這時可以往「倍率孔」投珠，倍率分 2、4、6、8、10 倍，每升一段直接扣 2 顆，手上不足 2 顆就不能升（`X`）
   - 倍率越高，定燈後亮的 LED 越少：2 倍亮 5 顆，10 倍只亮 1 顆
3. **定燈**：按前面板的藍色按鈕，燈停下來，決定這一局哪幾排有獎。定燈後不能再投倍率孔（`D`）
4. **投珠孔**：定燈後往「投珠孔」投珠，投幾顆都可以，左上角用數字顯示（`B`）
5. **發射**：在檯面上按住滑鼠（或 `空白鍵`）拉長彈簧，放開發射，按越久彈越遠。力道不夠，鋼珠會滾回發射口，可以再射一次
6. **計分**：鋼珠落在**有亮燈的那一排**才算中，得珠 = 倍率 × 投珠數，從出珠口一顆一顆掉進托盤。沒中就銘謝惠顧，投進去的珠都收走

`M` 靜音、`H` 玩法說明（手機版點上方的「?」）。

**紀錄**：「最高分」（單局最高得珠）和「最多持珠」都存在瀏覽器 localStorage，重新整理或關掉再開都會保留。

## 檔案

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 頁面結構與側邊面板 |
| `style.css` | 樣式與手機版排版 |
| `game.js` | 規則、物理（釘陣、發射彎軌、落點隔板、托盤）、繪圖、音效與操作 |

規則數值在 `game.js` 最上方：`MULTS`（倍率段數）、`MULT_COST`（升一段扣幾顆）、`litFor`（各倍率亮幾顆燈）、`COIN_BALLS`、`SLOT_COUNT`。
